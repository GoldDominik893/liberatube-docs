# Maintenance

In order to keep your Liberatube instance running smoothly, you shall follow these steps every few weeks or more often.

## Database Maintenance

The Liberatube system stores the Trending page, All videos successfully loaded and the number of dislikes a video has, inside a SQL database for speed and reliablilty. The data will build up to a few GB on a large instance. 

You can remove records older than the cache time(default 4 hours) from the database by using this query below.

```sql
USE users;
DELETE FROM cache_video
WHERE created_at < NOW() - INTERVAL 4 HOUR;
DELETE FROM cache_dislike
WHERE created_at < NOW() - INTERVAL 4 HOUR;
DELETE FROM cache_trending
WHERE created_at < NOW() - INTERVAL 4 HOUR;
```

You can set this up as a cron job or perform this manually. However liberatube will soon be switching to automatic maintenance where it will automatically remove records which are older than the specified cache time specifed in the configuration file.

## Updates

It is recommended that you keep your Liberatube instance up to date with at least the newest release on GitHub.

Check out [The updating guide](5.updating.md) for info on how to update Liberatube.
